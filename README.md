# Тайный Санта

Организатор создаёт комнату, указывает бюджет и дату, добавляет своё фото и пожелания. Гости вступают по общей ссылке. После жеребьёвки каждый участник открывает свою личную ссылку и видит получателя с его вишлистом.

[Сайт на GitHub Pages](https://relaxerr.github.io/secret-santa/) · [Демо в одной вкладке](https://relaxerr.github.io/secret-santa/demo.html)

## Как играть

1. Создайте комнату и заполните профиль. Для участия нужны фото и хотя бы одно пожелание. Ссылка на подарок необязательна.
2. Сохраните личную ссылку для возвращения. Она даёт доступ к вашему профилю. Друзьям отправляйте общую ссылку приглашения.
3. Когда зарегистрировались минимум три человека, обновите комнату и подтвердите жеребьёвку. Каждый дарит один подарок и получает один. После распределения состав и пожелания закрыты.
4. Участники открывают свои личные ссылки и смотрят результат. Для уже открытой комнаты предусмотрено ручное обновление.

## Разработка

Нужен Node.js 24. Из корня репозитория выполните `node scripts/serve.mjs` и откройте http://127.0.0.1:4173/. Основная страница использует настроенный Apps Script. Для локальной демонстрации без Google откройте `/demo.html`.

`node scripts/verify.mjs` проверяет синтаксис, запускает тесты и собирает статический сайт в `dist/`. Код сайта находится в `web/`, серверные обработчики в `backend/`. Внешних пакетов для сборки нет.

## Эксплуатация

На Pages публикуются только статические файлы из gh-pages. Команда выпуска — `bash scripts/publish-pages.sh`. Google Apps Script обновляется отдельным развёртыванием. В GitHub хранится только публичный адрес веб-приложения (`APPS_SCRIPT_URL`). Идентификатор закрытой таблицы хранится в Script Properties. Таблицу и распределения видит владелец Google-проекта.

См. [инструкцию развёртывания](docs/deployment.md) и [лимиты сервиса](docs/operations.md).

# Тайный Санта

Веб-приложение для организации обмена подарками без аренды сервера.
Интерфейс размещается на GitHub Pages, серверная логика — в Google Apps Script,
данные планируется хранить в закрытой Google Таблице.

## Текущее состояние

Начальный каркас, не готовый сервис жеребьёвки. Есть адаптивная стартовая страница,
сборка, CI, публикация Pages, диагностическая страница Apps Script, глобальный бюджет
запросов и обработка ошибок. Локальное демо комнат, пожеланий и жеребьёвки доступно в одной вкладке.
Серверная авторизация и сохранение игровых данных в Sheets запланированы. См. [план](docs/roadmap.md).

## Локальный запуск

Нужен Node.js 24. Внешних пакетов и обязательного npm install нет.

```sh
node scripts/serve.mjs
# Открыть http://127.0.0.1:4173
node scripts/verify.mjs
```

Сборка: `node scripts/build.mjs`, результат — `dist/`.
Сервер разработки раздаёт `web/`; сгенерированная конфигурация находится только в `dist/`.
Необязательная публичная переменная `APPS_SCRIPT_URL` встраивается при сборке.
`.env` автоматически не загружается. Секретов в клиентской конфигурации быть не должно.

## Структура

```text
web/                Статический интерфейс (ES modules)
backend/            Исходники Google Apps Script и manifest
scripts/            Проверка, сборка и локальный сервер
tests/             Node tests серверных правил с изолированными Google mocks
docs/              Архитектура, продукт, API, данные, эксплуатация и план
.github/            Проверки PR, публикация Pages и шаблоны
```

## Автоматизация

`Checks`: pull request и push в main → синтаксис, тесты и сборка.
`Publish Pages`: main или ручной запуск → те же проверки → artifact → GitHub Pages.
Apps Script публикуется вручную, отдельно от Pages; инструкция и smoke checks — в docs/deployment.md.
Удалённый репозиторий, Google Таблица и deployment не создаются локальной инициализацией.

Лицензия пока не выбрана: публикация исходников сама по себе не предоставляет разрешения на их использование.

## Демо пользовательского сценария

После запуска локального сервера откройте http://127.0.0.1:4173/demo.html.
На главной нажмите «Создать комнату», заполните название, бюджет и дату.
Далее добавьте профиль создателя и хотя бы одно пожелание. В комнате нажмите
«Пригласить участника» и добавьте ещё двух человек. Для каждого участника
обязательны имя и фото. К каждому пожеланию можно приложить отдельную ссылку.
Переключитесь на организатора через «Демо-роль», начните жеребьёвку и подтвердите
распределение. После этого каждому профилю доступен экран «Ваш получатель».

Демо хранит данные в памяти одной вкладки. Переключатель ролей служит для
проверки экранов и даёт проверяющему доступ ко всем ролям. Для реального
обмена подарками нужны серверная авторизация и общая комната между устройствами.

# Работа с проектом

- Сначала прочитай README.md и docs/architecture.md, для серверных изменений — docs/security.md и docs/operations.md.
- Стек: статические ES modules, Node 24 для инструментов, Google Apps Script V8 и Google Sheets.
- `node scripts/verify.mjs` — обязательная локальная проверка перед коммитом.
- Не добавляй зависимость без практической необходимости. npm для текущего каркаса не требуется.
- Не коммить токены, реальные имена участников, распределения, Sheet ID, .clasp.json или OAuth credentials.
- Функции Apps Script с суффиксом `_` приватны для google.script.run. Открытый RPC обязан валидировать запрос, доступ и лимиты.
- Доступ к странице/Origin не заменяет авторизацию. Лимиты приложения не являются защитой от исчерпания квот Google.
- Не заявляй, что комнаты или жеребьёвка работают, пока они не реализованы и не проверены.
- Сохраняй относительные пути статических ресурсов для Pages project URL.
- Публикацию Apps Script проверяй вручную в анонимном окне. Node mocks не подтверждают работу Google.

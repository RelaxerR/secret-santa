# Хранение комнат

Скрипт открывает таблицу из SPREADSHEET_ID и создаёт технический лист SantaRoomsV1. Одна строка представляет одну комнату: ключ, срок действия, JSON метаданных и до 50 ячеек участников. Профиль содержит уменьшенный JPEG, пожелания, идентификатор и хеш личного ключа. После розыгрыша добавляется идентификатор получателя.

Метаданные и профили записываются JSON-объектами, поэтому пользовательское имя или пожелание не занимает отдельную исполняемую ячейку. Сервер сериализует операции с помощью ScriptLock и записывает коммит комнаты одним setValues. При повторном создании, регистрации или розыгрыше с теми же ключами возвращается существующий результат.

Комната доступна 90 дней с создания. Просроченные строки очищаются при следующем запросе к хранилищу. Для удаления во время простоя настройте ежедневный триггер purgeExpiredRooms_. Владелец таблицы имеет доступ к исходным данным комнаты.

# Архитектура

Pages раздаёт HTML, JavaScript, CSS, шрифт и иллюстрацию. Основной интерфейс обращается к публичному /exec Apps Script. POST содержит JSON с Content-Type text/plain, браузер следует редиректу ContentService. Доступ с нового домена или после публикации новой версии проверяется живым запросом в браузере.

Секрет приглашения разрешает регистрацию. Личный ключ разрешает чтение своего профиля и результата. Сервер определяет права организатора и проверяет состояние комнаты при каждой операции. Вводимые пользователями названия и имена отображаются как текст.

Постоянное хранилище — закрытая Google Таблица владельца. Исходные фотографии перед отправкой преобразуются в небольшие JPEG-аватарки. Набор участников и состояние жеребьёвки принадлежат серверу. Страница demo.html сохраняет отдельный демонстрационный сценарий внутри одной вкладки.

Диагностика открывается по GET, комнаты используют POST. Лимиты и ошибки передаются в JSON. Если Google отклоняет запуск или возвращает страницу авторизации, клиент сообщает о недоступности.

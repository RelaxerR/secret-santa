# API

GET /exec открывает страницу диагностики. Для игры браузер отправляет POST /exec с JSON в теле и Content-Type text/plain. Секреты приглашения и участника передаются в теле. Сервер отвечает JSON с полями ok и data либо ok и error. Приём ответа обязателен для подтверждения операции.

| action | Доступ и параметры |
| --- | --- |
| create | Новые roomId, invite, token, room и профиль создателя |
| peek | roomId, invite. Возвращает сведения о комнате и её состоянии |
| join | roomId, invite, новый token и профиль |
| state | roomId и личный token |
| edit | roomId, token и новый список wishes до жеребьёвки |
| draw | roomId и token организатора. Повтор возвращает прежний результат |
| delete | roomId и token организатора. Удаляет данные комнаты |

Каждый ключ — 32 случайных байта в виде 64 строчных шестнадцатеричных символов. Состояние участника включает состав комнаты, его собственный вишлист и после жеребьёвки данные его получателя. В профиль входят name, photo и wishes. Пожелание содержит text и необязательный url с протоколом http или https.

Ошибка содержит code, message и retryAfterSeconds, если время известно. Сбой сети после записи оставляет результат неопределённым для клиента. Повтор create/join должен использовать те же идентификаторы и ключи.

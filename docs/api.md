# API

## Реализовано

`doGet()` отдаёт HTML Service Status.html, без данных участников.
`serviceStatus()` — единственный открытый RPC для google.script.run. Ничего не записывает в Sheets.
Читает SERVICE_ENABLED и расходует общий бюджет запросов, если сервис включён.

Успех: `{ ok: true, data: { status: "ready", version: "0.1.0" } }`.
Ошибка: `{ ok: false, error: { code, message, retryAfterSeconds: number | null } }`.
HTTP-код не используется как код доменной ошибки: RPC имеет собственную оболочку.

| code | Значение |
| --- | --- |
| MAINTENANCE | Сервис выключен владельцем |
| BUSY | Не удалось получить блокировку, повторить вручную позже |
| RATE_LIMITED | Превышен общий минутный бюджет |
| DAILY_LIMIT | Превышен общий суточный бюджет, сброс в 00:00 UTC |
| QUOTA_EXCEEDED | Перехвачена ошибка квоты Google, точное время восстановления неизвестно |
| UNAVAILABLE | Неожиданная ошибка без раскрытия подробностей |

Если Google не запускает скрипт, оболочки нет вообще. Клиент должен показывать
UNAVAILABLE с формулировкой «Возможно, исчерпана квота Google или возникла проблема со связью».
Сетевую ошибку нельзя достоверно называть исчерпанием квоты.
Текущая диагностическая страница обрабатывает RPC failure и таймаут 20 секунд;
при блокировке самого /exec вместо нашей страницы может появиться страница ошибки Google.

## Запланировано, не реализовано

createRoom, joinRoom, getRoom, updateWishes, closeRegistration, draw, getRecipient, deleteRoom.
Окончательные DTO и транспорт фиксируются после spike, до кода комнат.
Все мутации требуют авторизацию, валидацию и idempotency key; клиенту не возвращается полное распределение.
